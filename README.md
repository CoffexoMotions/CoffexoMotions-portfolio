# CoffexoMotions - Video Editing Portfolio

A modern, clean personal portfolio website for showcasing video editing work. Built with HTML and CSS, featuring a warm cream and brown color scheme.

## 🎨 Design Features

- **Warm Color Palette**: Cream background (#E8DCC8) with dark brown accents (#5C3D2E)
- **Modern UI Elements**: Rounded corners, bordered cards, and smooth hover effects
- **Responsive Layout**: Adapts seamlessly to all screen sizes
- **Professional Navigation**: Pill-shaped brown navbar
- **Circular Profile Badge**: Eye-catching hero section with animated profile
- **Portfolio Grid**: Clean grid layout for video showcases
- **Experience Cards**: Organized skill showcase

## 📁 File Structure

```
CoffexoMotions-portfolio/
├── index.html       # Main HTML file
├── styles.css       # Complete styling
└── README.md        # This file
```

## 🚀 Quick Start

1. Open `index.html` in your browser
2. Customize your content
3. Add YouTube video IDs
4. Deploy to GitHub Pages

## 🎬 Adding YouTube Videos

Find your YouTube video ID from the URL: `youtube.com/watch?v=VIDEO_ID`

Replace in the portfolio cards:
```html
<iframe src="https://www.youtube.com/embed/VIDEO_ID"></iframe>
```
